# Supplied peptide teacher

`teacher_canya_cpad.pt` is the unchanged CAnYA shared-supervised → CPAD final teacher. SHA256 and size are recorded in `metadata.json`. It is a trained model checkpoint, not generated HAPR/ESM-2 feature data. Teacher inference still needs compatible ESM-2 8M backbone assets. CAnYA pretraining additionally needs its original initializer; no initializer is invented or substituted here.
