# Encoder feature directory

This directory is reserved for feature utilities. The active window-token, zero-base and HAPR extraction programs are in [`../scratch/get_feature/`](../scratch/get_feature/); cache loading is implemented in [`../my_loader/window_data.py`](../my_loader/window_data.py).

Generated window tokens, HAPR, pAPR and rAPR arrays are stored in the output directories specified by the extraction commands. See the [encoder README](../README.md) for usage.
